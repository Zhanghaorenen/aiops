## 部署验收边界

- Langfuse 已验证本地接收端的 OTLP 协议、关联与脱敏；实际 Langfuse 项目界面仍需目标环境的地址和密钥验收。
- 远程 MCP 验证使用测试 issuer、签名令牌及进程内 HTTP 传输。公网 TLS 代理、真实 IdP 登录、客户端注册和委托令牌轮换还需目标部署验证。
- 前端结果经过组件渲染和构建，没有进行人工浏览器验收。大规模历史知识库迁移、长期运转和生产负载下的 P95 未实测。
- 首次评测与故障注入只使用模拟业务场景。没有在现有业务库运行迁移，也没有重启生产服务或干预训练进程。

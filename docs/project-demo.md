# 功能演示

演示分为界面模式和真实环境模式。界面模式在登录页选择“演示环境”，只能说明交互设计；训练任务、模型和监控效果需要真实环境。展示前准备自己的非敏感文档，隐藏账号、地址、进程路径、令牌和私人知识内容。

1. **约 1 分钟：场景与架构。** 解释多用户共享 GPU 为什么还需检查整机 RAM，打开总览说明指标来源、采样时间与缺测状态。
2. **约 2 分钟：训练准入。** 在隔离演示环境或测试数据库登记两个任务，展示 SHARED / EXCLUSIVE 与跨 GPU RAM 冲突。说明这是逻辑承诺，不启动训练或锁定显存。尚无真实环境时改用源码及测试结果讲解，不向生产数据插入假样本。
3. **约 1 分钟：进程与身份。** 展示 PID、启动时间、用户及显存；说明 PID 复用、无权限字段与 EXITED_UNKNOWN 的处理。
4. **约 2 分钟：AI 与知识库。** 查询授权服务器和任务，观察 SSE 工具状态、实际采样时间与引用。区分模型建议和已确认故障。无模型配置时展示工具实现与测试，不伪造回答。
5. **约 1 分钟：权限与验证。** 对照 VIEWER / ADMIN 的可用操作，展示测试与 CI 的实际结果，说明 V0.4 联合验收和规模验证仍待完成。

# 需求清单

## V0.1 范围

| 领域 | 范围 | 当前状态 |
| --- | --- | --- |
| 认证 | 登录、JWT、当前用户、改密、管理员初始化 | 后端基础已实现，JWT 2 小时，BCrypt 密码 |
| 服务器资产 | 节点列表/详情、操作系统和硬件信息、在线状态 | 后端基础已实现：独立节点表、列表/详情和最新指标 |
| Agent 接入 | 限时单次注册令牌、注册换取凭证、凭证认证、心跳和重复注册 | 后端基础闭环已实现；速率限制与凭证轮换待加 |
| 监控 | CPU、内存、磁盘采样、历史和最新值 | 后端基础已实现采样保存、最新和时间范围查询；清理策略待加 |
| Python Agent | 真实采集、注册、心跳/采样、重试、配置 | 已实现基础版本；需实机双平台验证 |
| 前端 | 登录、服务器列表/详情、指标展示、Token 生命周期 | 已实现登录、列表、详情、趋势图及退出；尚无令牌签发管理界面 |

## 后续版本

- V0.2：分组、磁盘/网络/GPU 明细、历史曲线、指标保留策略和告警规则。
- V0.3：Docker/进程/日志只读查询、审计和运维任务状态机。
- V0.4：模型服务与推理监控、AI 助手只读工具调用、诊断记录。
- V0.5：审批、受控任务执行、结果验证、知识库/RAG 和部署自动化。

跨版本要求：AI 结论必须引用采集数据或工具结果；危险操作必须授权、审批并审计；凭证和密码不得明文保存；用户 API 与 Agent API 使用独立认证边界。

## V0.1 验收

- 空 MySQL 数据库可通过版本化迁移初始化；管理员由显式环境变量初始化，密码使用 BCrypt。
- 未认证用户 API 返回 401；用户可登录、获取当前用户及修改密码。
- Agent 只能使用一次性/限时注册令牌注册，重复注册有明确的幂等策略；持久化只保存令牌/Agent 凭证摘要。
- Agent 凭证只能访问心跳和指标写入端点；心跳超时后节点状态转为离线。
- 服务器资产与 Agent 实例分表；指标可按节点查询最新值和时间范围历史值。
- Python Agent 在 Linux/Windows 从真实系统采集 CPU、内存、磁盘并重试网络错误。
- 前端登录、列表、详情与指标视图连接真实 API，支持退出和 Token 失效处理。

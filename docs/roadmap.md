# 开发路线

## 阶段 0：审查与方案

- 盘点本地工程，记录依赖、接口、持久层和安全缺口。
- 固定领域模型、认证边界、迁移方案与 API 契约。
- 验收：文档和实现状态一致；Boot 4 兼容选择有依据。

## 阶段 1：数据库与认证

- 加入 Flyway、用户/登录记录迁移、管理员环境变量初始化、BCrypt、JWT 和 Spring Security。
- 验收：空库迁移、登录、401/403、当前用户、改密和密码哈希验证。

## 阶段 2：节点与 Agent

- 节点和 Agent 分表；限时单次注册令牌摘要；Agent 凭证摘要、重复注册策略、心跳和离线判断。
- 验收：无凭证无法注册/写入；凭证仅能访问 Agent API；Agent 与节点可独立识别。

## 阶段 3：监控

- 容量指标模型、校验、最新及时间范围查询、保留策略。
- 验收：真实写入 MySQL，跨节点隔离正确，范围和上限校验正确。

## 阶段 4：Python Agent

- psutil 采集、配置、注册、重试退避、HTTP 超时和信号退出。
- 验收：Linux/Windows 启动说明明确，指标来自本机，断网后可恢复。

## 阶段 5：最小前端

- 登录、Token 管理、列表、详情、最新指标和历史曲线。
- 验收：构建通过，401 退回登录，页面对空数据和网络错误可用。

## 后续

- 告警、日志/容器只读、审计与受控任务、AI 只读诊断、审批和私有化部署。每阶段单独定义容量、安全和回滚标准。

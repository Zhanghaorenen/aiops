# Agent 采样中断排查 SOP

## 适用范围与故障现象
用于服务器页面的采集时间停止更新、Agent 离线或上报失败。记录服务器 ID、最后心跳、collectedAt、receivedAt 和异常开始时间。本文是排查流程，不是对当前服务器故障的声明。

## 可能原因与证据
可能是中心后端未启动、Tailscale 链路不可达、用户级采集服务未运行、凭据无效或 GPU 的 NVML 采集单独失败。每项都需要对应证据，不能仅凭一条告警认定机器断电。

## 只读排查步骤
1. 查看前端和后端健康检查是否可访问，核对中心电脑是否开机。
2. 由人员查看采集服务状态和最近日志，enabled 不等于 running。
3. 比较主机与 GPU 的原始采样时间，区分未上报、无设备和采集失败。
4. 检查授权、端口和 Tailscale 连通性，不能通过关闭认证来解决 401 或 403。

## 预期结果与处理边界
服务状态可读，日志能定位错误类别，采样时间可与中心接收时间对照。凭据保留在受限状态文件，不粘贴到知识库。AI 只给建议，不自动执行 SSH、重启服务、删除文件或停止训练任务。

## 恢复验证
由授权人员处理后，观察至少三个采样周期，确认原始采集时间持续增加、主机及 GPU 状态符合实际、数据库有新样本。默认采样间隔约 15 秒；过期值和缺失值不能当成零或恢复证据。保留处理人、处理时间和复查结果。
